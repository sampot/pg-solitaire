# 接龍（Klondike）

電腦課經典的單人撲克接龍。把 52 張牌從 7 列牌堆與翻牌堆中，依花色由 A 到 K 建到基座即完成。

## 玩法

1. 按下「翻牌堆」把牌翻到翻出區。
2. 點選可移動的牌（牌面朝上且能合法移動的商品），再點目標列或基座放下。
3. 列上需**異色、小一階**才能相接；基座需**同花色、升序**（從 A 開始）。
4. 四堆基座都收到 K 即接龍完成；用時與步數越少越好。

## 操作

- **滑鼠／觸控**：點選牌 → 點目標位置移動；點牌堆翻牌。
- **自動整理**：把能上基座的牌自動放上去（提示）。
- **重新發牌**：重來一局。

## 技術

- `game.js`：純函式規則邏輯（發牌、翻牌、移動、暫存、A→K 建堆、自動整理、勝利判定）— 可單元測試。
- `app.js`：DOM 拖曳／點擊互動與渲染。
- `audio.js`：Web Audio 即時合成音效，無第三方音檔。
- 最佳用時存 `/api/kv/pg-solitaire-best`（Playgrounds KV）；無 KV 環境照玩。
